# Media

Screenshots/GIFs referenced by the README live here. The README has a commented-out image
block ready to go — drop the file in and uncomment the line.

## Wanted
- **`tracker.png`** — the **Drafts** tab of a tracker, showing the **Status** column with the
  Pending / Approved / Sent color-coding (and a couple of drafted rows). This is the money shot:
  it shows the approve-to-send loop at a glance. Redact real names/emails before capturing.
- *(optional)* **`digest.png`** — a sweep digest email in the inbox.
- *(optional)* **`loop.gif`** — a ~15–20s screen capture: a reply arrives → a Pending draft appears
  → you flip it to Approved → it sends.

## Tips
- Aim for ~1200–1600px wide; PNG renders reliably on GitHub (SVG can be blocked in README markdown).
- After adding `tracker.png`, open `../../README.md`, find the "How it works in 30 seconds"
  section, and uncomment the `![...](docs/media/tracker.png)` line.
- Never commit real prospect data — blur or use a throwaway/demo campaign for the capture.
